## 操作卡片：旧安装介质候选

| 字段 | 示例内容 |
|---|---|
| 发现 | 用户指定的下载区域存在一个 3.2 GB 安装介质候选；路径已在示例中省略 |
| 证据 | 只读枚举得到类型、大小和最后修改时间；未读取文件内容 |
| 预期收益 | 若用户确认不再需要，最多回收约 3.2 GB 逻辑大小；卷可用空间以删除后实测为准 |
| 功能影响 | 以后离线重装该软件需要重新获取安装介质 |
| 风险 | R1；目标精确、用户可识别、删除后可从回收站恢复，但是否仍需离线安装尚未确认 |
| 动作 | 保守建议模式下等待用户确认这个单独候选；不与缓存或应用目录成批处理 |
| 备份 | 使用回收站作为短期可恢复位置；执行前确认其容量和策略 |
| 回退 | 从回收站还原到原位置；若回收站不可用则停止，不执行永久删除 |
| 验证 | 比较操作前后卷可用空间，并确认对应软件仍能启动、安装来源仍可获得 |
| 停止条件 | 用户仍需该介质、恢复条件不成立、卷空间达到健康阈值，或继续候选的收益不值得风险 |

## 本轮结论

- 只读扫描完成；没有更改 Windows、应用或用户数据状态。
- 内存读数没有显示需要优化的证据，因此没有提出关闭服务或分页文件的建议。
- 一个 R1 空间候选等待确认；R2–R4 动作均未提出。
- 最终报告在分享前仍需由用户检查软件名称、卷标签和可能敏感的非系统路径。
