# 示例提示词

把方括号里的内容换成你的情况。首次使用时，最好同时说明 Windows 版本、设备用途、必须保留的功能和希望采用的模式。

## 先做整机只读检查

```text
请使用 windows-safe-optimizer 检查这台 [Windows 10/11] 电脑。
我选择保守建议模式。它主要用于 [办公/游戏/开发]，[列出必须保留的功能] 不能受影响。
先做只读检查，把报告写到我稍后指定的目录；不要修改设置。
```

## C 盘空间不足

```text
请使用 windows-safe-optimizer 的磁盘与空间模块。
C 盘只剩 [数字] GB，我需要保留 OneDrive、休眠和 [某个应用]。
我选择 [保守建议/深度协作] 模式。先告诉我扫描根目录、排除项和重解析点边界，再生成候选清单。
```

## 内存或启动慢

```text
请使用 windows-safe-optimizer 检查开机后的内存和启动负载。
不要按进程数量或单次占用判断。请设计一次重启后静置基线，说明每个候选的所有者、用途、影响和复测方式。
我选择保守建议模式。
```

## Codex 或代理持续重连

```text
请使用 windows-safe-optimizer 的网络与代理模块。
普通网页 [能/不能] 打开，但 [Codex/某个应用] 会 [断线/重连]。我使用 [系统代理/Clash/VPN]。
先设计不暴露凭据的 DNS、TLS、HTTP、SSE 和 WebSocket 分层测试；任何配置变化都要先记录原值和恢复步骤。
```

## 新电脑开荒

```text
请使用 windows-safe-optimizer 为这台 Windows 11 新电脑制定开荒顺序。
它属于 [个人/公司/学校]，主要用于 [用途]。我选保守建议模式。
先处理更新、安全、恢复、备份和账户角色；不要自动安装通用软件包，也不要批量卸载预装应用。
```

## 只整理界面与通知

```text
请使用 windows-safe-optimizer 整理开始菜单、任务栏和通知。
我想减少 [推荐内容/普通应用通知/后台提醒]，但必须保留安全、更新、账号异常和 [指定应用] 的提醒。
逐项列出设置路径、影响和回退，不要顺便改动其他模块。
```
